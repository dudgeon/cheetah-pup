Confirm on hardware before printing

    Regenerate: python -m cad.assembly (STEP, STL, mass properties, viewer meshes) → python -m cheetah_pup.mjcf sim/cheetah_pup.xml and --rl → python -m cheetah_pup.validate → python -m cheetah_pup.build_cad_review. Parts are modelled in their MuJoCo body frames, so the STL files drop into the model without transforms.

    Gait playback is the open-loop MuJoCo recording (inverse-kinematics targets, no balance feedback) between 3 and 5 s, shown in place. See DR-02 for the full runs and the torque/speed traces.
